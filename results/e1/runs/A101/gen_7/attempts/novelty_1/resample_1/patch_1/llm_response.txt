<DESCRIPTION>
Uses a win-stay, lose-shift strategy: begin cooperatively, retain the previous action after matching actions, and switch after mismatches. This preserves mutual cooperation while responding more effectively to exploitable or alternating opponents than simple tit-for-tat.
</DESCRIPTION>

# EVOLVE-BLOCK-START
def policy(own_history, opponent_history):
    return 0 if len(own_history) == 0 else (own_history[-1] if own_history[-1] == opponent_history[-1] else 1 - own_history[-1])
