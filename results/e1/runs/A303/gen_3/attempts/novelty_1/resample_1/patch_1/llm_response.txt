<DESCRIPTION>
Uses win-stay, lose-shift behavior: cooperate after mutually cooperative rounds or successful defections, and switch after receiving a poor payoff. This preserves cooperation with reciprocal opponents while quickly adapting to persistent defection.
</DESCRIPTION>

```python
# EVOLVE-BLOCK-START
def policy(own_history, opponent_history):
    if len(opponent_history) == 0:
        return 0
    if opponent_history[-1] == 0:
        return own_history[-1]
    return 1 - own_history[-1]
# EVOLVE-BLOCK-END
```
